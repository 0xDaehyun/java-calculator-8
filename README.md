## 구현할 기능 목록
- [ ] 빈 입력 처리: "" → 결과 0 출력
- [ ] 기본 구분자 처리: "," ":" 기반 분할 및 합산
- [ ] 커스텀 구분자 파싱: "//<구분자>\n" 또는 "//<구분자>\\n"
- [ ] 유효성 검증:
    - [ ] 연속/말단 구분자 금지 (빈 토큰 → 예외)
    - [ ] 공백/탭/추가 개행 금지
    - [ ] 숫자만 허용(양수)
    - [ ] 잘못된 값은 IllegalArgumentException 발생
- [ ] 출력 형식: "결과 : <합>"
- [ ] I/O: Console.readLine() 사용, System.exit() 미사용
